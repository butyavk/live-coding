Every topic of this site on one map, in six stages from orientation to the last days before the interview. The overview tree at the top shows how the topics build on each other; below it, the same topics are listed by stage. Each topic shows whether you have learned it, opened it or skipped it, and how many of its exercises have passed Check. Select a topic to see what to learn first and what it leads to. The map follows your reading: pages you open are marked, and you mark a topic as learned at the end of its page.

## The six stages

| Stage | Sections | When the stage is done |
|---|---|---|
| Get oriented | Start here | You know what the interviewer checks, how to spend the time, and what is in the practice data. |
| SQL foundations | SQL foundations | You can filter, group and join without losing rows, zeros or the last day of the month. |
| SQL patterns | SQL patterns | You recognise the pattern behind a task: best per group, every day, two sources, duplicates, a balance. |
| Python for live coding | Python for live coding | You write a correct function in small steps with the standard library, and name its complexity. |
| Interview tasks | Practice: SQL tasks, Practice: Python tasks | You solve a task out loud within its clock: questions first, a check before "done", a follow-up answered. |
| Before the interview | Reference | The recipes fit on one sheet, you know the common mistakes, and the facts come back in seconds. |

A few things follow from the prerequisites:

- **SQL starts from the data.** The first SQL page needs only the [practice dataset](/start/dataset/), and the SQL patterns build on the foundations.
- **Python runs in parallel.** The Python pages need only the [introduction](/start/introduction/), so you can mix SQL and Python days. Only [Python and SQL](/python/python-and-sql/) needs a SQL page first.
- **Tasks come after the topics, and need the protocol.** The first SQL and Python task groups need the [interview protocol](/start/interview-protocol/) and the topic pages they are built from.
- **Reference comes last, but stays open.** The recipes, the cheat sheets and the common mistakes sum up the pages they link to, so the map puts them after those pages, as the last phase of the study plan does. The glossary needs only the dataset and the flashcards only the introduction. You can look anything up at any time.

## How to read the map

- **The overview tree** reads left to right: each topic sits to the right of the topics it builds on, and the lines between them are prerequisites. **Full screen** opens the tree over the whole window; Esc closes it.
- **Stages** in the list under the tree run top to bottom, in the order the [study plan](/start/study-plan/) uses. Each stage ends with what you should be able to do once it is done.
- **Lines** light up when you select a topic: solid teal lines come from the topics to learn first, dashed amber lines go to the topics it unlocks.
- **The topic card** opens when you select a topic. On the tree it docks at the right of the map (under it on a narrow screen). It shows the topic's status and reading time, what to learn first and what it leads to, and **Path here**: the topics on the way that you have not learned yet, how long they take to read carefully, and roughly how many days learning them takes in each plan.
- **Ready** means every topic it needs is learned, so the page will make sense now. **Skipped** marks a topic that something you have already learned builds on: a gap worth closing before the interview.
- **Next up** shows the next three steps of your plan that you have not learned yet, in the order of the [study plan](/start/study-plan/). The plan puts every prerequisite first, so the first one is always ready. Pick a plan above the map: next to it you see its length and its number of steps, the same as in the study plan. Topics outside it fold into small dots; the dotted ones are optional in that plan. The long plan covers every topic.
- **Exercises.** A topic with exercises shows how many of them have passed Check, for example "2/3", in its card and in the list. **Every exercise solved** lists the topics whose exercises all pass but which are not marked as learned yet: one click marks them.
- **Prerequisites are few on purpose**: only what a page really relies on. You can read in any order; the map only shows where the ground is firm.

## Your progress

- Pages you open are marked as opened automatically. Mark a topic as learned at the end of its page, in its card on this map, or by ticking it in the [study plan](/start/study-plan/): all three set the same mark.
- Progress lives only in this browser. There is no account, and nothing is sent anywhere, so another browser or device starts empty, and clearing the site's data erases it.
- To move it, use **Download progress** under the map and **Load progress** on the other device.
- **Reset progress** is the same here and in the study plan: it clears the pages marked as learned, the pages opened, the plan ticks and the solved exercises. Tick **Also delete the code drafts and the task timers** to clear those too. The chosen plan stays. The [flashcards](/reference/flashcards/) keep their own progress and their own reset.
- **Map look** at the top of the map switches between **Classic** and **Dark fantasy**, a skill-tree look. The topics and your progress stay the same.
