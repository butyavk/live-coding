## Licences

The project has two licences:

It covers the pages, the exercises and their reference solutions, the flashcards and the practice dataset, unless a file says otherwise.

Third-party libraries used to build and run the site keep their own licences (see below).

The MIT License lets you use, copy and change the code for any purpose, as long as you keep the copyright notice and the licence text. CC BY 4.0 lets you share and adapt the content, including commercially, as long as you:

1. **Credit** this site, with a link.
2. **Link to the licence**: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
3. **Say whether you made changes.**
4. **Do not imply endorsement** by this site's maintainers.

## The dataset and the tasks

The dataset and the tasks are invented for this site. Every row of the practice data was generated: the merchants, products, customers, prices, payouts and advances are made up, and so are the two partner marketplaces. Names such as "Pocket Quest" or "North Market" are invented, and the numbers do not describe any real business.

The site was written with the help of an AI assistant; every exercise, query and number is checked by automated tests.
