## Лицензии

У проекта две лицензии:

- **Код** сайта, его компонентов, сред выполнения и скриптов распространяется по [лицензии MIT](https://opensource.org/license/mit).
- **Материалы** на русском и английском языках распространяются по лицензии [Creative Commons «Атрибуция» 4.0 Международная (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/deed.ru). Это относится к страницам, упражнениям и их эталонным решениям, карточкам и учебным данным, если в файле не сказано иное.

Сторонние библиотеки, на которых собран и работает сайт, сохраняют собственные лицензии (см. ниже).

Лицензия MIT разрешает использовать, копировать и изменять код для любых целей, если сохранены уведомление об авторских правах и текст лицензии. CC BY 4.0 разрешает свободно распространять и переделывать материалы, в том числе в коммерческих целях, при условии, что вы:

1. **Указываете авторство**: этот сайт со ссылкой.
2. **Даёте ссылку на лицензию**: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.ru).
3. **Сообщаете, вносили ли изменения.**
4. **Не создаёте впечатления одобрения** со стороны тех, кто поддерживает сайт.

Пример строки атрибуции:

```text
Based on "Live Coding Map" (https://butyavk.github.io/live-coding/),
licensed under CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).
Changes: <describe your changes>.
```

## Учебные данные и задачи

Учебные данные и задачи придуманы для этого сайта. Каждая строка данных сгенерирована: продавцы, продукты, покупатели, цены, выплаты и авансы выдуманы, как и оба маркетплейса-партнёра. Названия вроде «Pocket Quest» или «North Market» придуманы, а цифры не описывают ни один реальный бизнес.

Сайт написан с помощью ИИ-ассистента; каждое упражнение, каждый запрос и каждое число проверяются автоматическими тестами.

## На чём построен сайт

Сайт и его упражнения работают на открытом программном обеспечении:

| Проект | Что делает здесь | Лицензия |
|---|---|---|
| [Astro](https://astro.build/) и [Starlight](https://starlight.astro.build/) | Фреймворк сайта и тема документации | MIT |
| [PGlite](https://pglite.dev/) | PostgreSQL, скомпилированный в WebAssembly: выполняет каждое упражнение по SQL в браузере | Apache 2.0 (или PostgreSQL License) |
| [Pyodide](https://pyodide.org/) | CPython, скомпилированный в WebAssembly: выполняет каждое упражнение по Python в браузере | MPL 2.0 |
| [CodeMirror](https://codemirror.net/) | Редактор кода в каждом упражнении | MIT |
| [PostgreSQL](https://www.postgresql.org/) | База данных, из которой собран PGlite | PostgreSQL License |
| [DuckDB](https://duckdb.org/) | Выполняет SQL в заданиях без сети | MIT |
| [pytest](https://docs.pytest.org/) | Проверяет задания без сети | MIT |
| [Onest](https://fontsource.org/fonts/onest), [JetBrains Mono](https://www.jetbrains.com/lp/mono/) и [Cormorant](https://fontsource.org/fonts/cormorant) | Шрифты текста, кода и карты навыков | SIL Open Font License 1.1 |
