Для инженеров данных, аналитиков и бэкенд-инженеров, которым предстоит лайвкодинг по SQL и практическому Python, и для русскоязычных инженеров, которые проходят интервью на английском. Сайт готовит именно к интервью **на английском**: условия задач, вопросы интервьюеру и фразы для рассуждений вслух — по-английски, как на настоящем интервью. К интервью на русском он готовит тоже: все объяснения — на русском. От сборников SQL-вопросов его отличают четыре вещи:

## Как пользоваться сайтом

<Steps>

1. **Прочитайте [введение](/start/introduction/)**: что проверяет интервью, как оно обычно устроено и как работает упражнение.

2. **Выберите [план подготовки](/start/study-plan/)** под свой срок и сверяйтесь с [картой навыков](/start/skill-map/). На карте видно, что пройдено, что пропущено и что дальше.

3. **Освойте [протокол](/start/interview-protocol/)** и проговаривайте [фразы для рассуждений вслух](/start/think-aloud/), пока они не пойдут сами. Затем познакомьтесь с [учебными данными](/start/dataset/): на них выполняется каждое упражнение по SQL.

4. **Пройдите темы**: основу SQL, приёмы SQL и Python. Решайте каждое упражнение, прежде чем открыть ответ, и угадывайте результат каждой ловушки до запуска.

5. **Решайте задачи как на интервью на время**: 25 минут, а самые сложные — за целевое время плюс 10 минут, вслух, с пустого редактора. Разбор открывайте только после успешной проверки.

6. **Перед интервью** проведите [мок-интервью](/start/mock-interview/), перепишите [приёмы](/reference/recipes/) на один лист, прочитайте [частые ошибки](/reference/common-mistakes/) и повторите [карточки](/reference/flashcards/).

</Steps>

## Что внутри

- **36 упражнений по SQL и 26 по Python.** В каждом один вопрос, редактор, запуск («Запустить»), проверка («Проверить») и эталонный ответ (Show answer).
- **23 ловушки SQL.** Короткие запросы, которые выглядят правильно, но работают не так. Угадайте результат, запустите, затем исправьте.
- **16 задач по SQL и 16 по Python как на интервью.** Условие, вопросы, которые стоит задать, пояснения к данным, эталонное решение и разбор. Три из них — задачи на отладку: рабочий код с ошибками и сообщение об ошибке.
- **Один набор учебных данных** для всех упражнений по SQL: продавцы, продукты, покупатели, четыре канала продаж, выплаты маркетплейсов и программа авансов. Семь таблиц, 8 294 транзакции.
- **Настоящие среды выполнения в браузере.** SQL работает на PostgreSQL, Python — на CPython, оба скомпилированы в WebAssembly. При первом запуске браузер скачивает около 19 МБ для PostgreSQL и 13 МБ для Python, дальше берёт их из кэша.
- **Карточки** с интервальными повторениями прямо в браузере и экспортом в Anki на русском и английском.
- **Прогресс сохраняется в браузере.** Карта навыков, план подготовки и карточки помнят, что вы уже сделали. Никуда ничего не отправляется.
- **Папка [`exercises/`](https://github.com/butyavk/live-coding/tree/main/exercises)** в репозитории — чтобы тренироваться без сети в своём редакторе: те же данные в DuckDB, задачи в виде файлов и проверки на pytest.
